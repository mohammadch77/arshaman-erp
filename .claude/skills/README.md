# اسکیل‌های Claude Code — پروژه ERP آرشامان

این پوشه شامل چهار Skill است. سه‌تای اول مخصوص همین پروژه‌اند (خودم نوشتم، از دل اسناد خودت)،
چهارمی رسمی Anthropic است (برای کیفیت طراحی UI).

## نصب (یک‌بار، همین حالا)

محتوای این پوشه را داخل ریشه پروژه Laravel، در مسیر `.claude/skills/` کپی کن:

```
arshaman-erp/                      ← ریشه پروژه (کنار artisan)
└── .claude/
    └── skills/
        ├── mary-ui-component/SKILL.md
        ├── session-closeout/SKILL.md
        ├── new-module-scaffold/SKILL.md
        └── frontend-design/
            ├── SKILL.md
            └── LICENSE.txt
```

اگر پوشه `.claude/skills/` هنوز وجود ندارد، بسازش. بعد از کپی، همین‌که Claude Code را در پوشه پروژه باز کنی
(دستور `claude`)، خودش این چهار Skill را می‌شناسد — هیچ تنظیم اضافه‌ای، فعال‌سازی دستی، یا restart لازم نیست.

## هرکدام کِی وارد عمل می‌شود

| Skill | Trigger می‌شود وقتی... | چه کاری می‌کند |
|---|---|---|
| `mary-ui-component` | یک کامپوننت Livewire/Blade ساخته یا ویرایش می‌شود | چک‌لیست تم مرکزی (رنگ/آیکون/لوگو/RTL/اعداد فارسی) را قبل از commit اجرا می‌کند |
| `session-closeout` | می‌گویی «تمام شد» / «کامیت کن» | ترتیب تست → مرور کد مالی → commit → آپدیت CLAUDE.md → یادآوری `/clear` را کامل طی می‌کند |
| `new-module-scaffold` | شروع یک ماژول کاملاً جدید (فازهای بعدی) | ساختار پوشه استاندارد Modular Monolith را می‌سازد |
| `frontend-design` | ساخت یا بازطراحی هر صفحه/کامپوننت UI | جلوی خروجی «قالب عمومی هوش مصنوعی» را می‌گیرد؛ قبل از کدنویسی یک جهت بصری مشخص انتخاب می‌کند |

## نکته درباره frontend-design و تم شما

این اسکیل رسمی برای انتخاب جهت بصری (فونت، رنگ، چیدمان) از صفر است. چون شما از قبل یک سیستم طراحی مشخص
(Mary UI + داسی‌یوآی + رنگ‌های `tailwind.config.js`) دارید، **این اسکیل جایگزین THEME_STRUCTURE.md نمی‌شود**
— اگر دو تا با هم تناقض داشتند (مثلاً این اسکیل فونت جدید پیشنهاد داد)، قواعد `CLAUDE.md` و `THEME_STRUCTURE.md`
همیشه اولویت دارند. بیشترین کمکش برای صفحاتی است که هنوز طرح دقیقشان مشخص نیست (مثل داشبورد تجمیعی فاز ۶).

## تست سریع بعد از نصب

بعد از کپی، در Claude Code یک درخواست بزن که یکی از Skill‌ها را trigger کند، مثلاً:
```
یک کامپوننت Livewire ساده برای فهرست شرکت‌ها بساز.
```
اگر `mary-ui-component` درست کار کند، باید ببینی که خودش سراغ `theme_icon()` و کلاس‌های semantic
داسی‌یوآی می‌رود بدون این‌که تو یادآوری کنی.

## اگر یکی درست trigger نشد

توضیح (`description`) بالای فایل SKILL.md همان چیزی است که Claude Code برای تشخیص «کِی استفاده کنم»
می‌خواند. اگر جایی trigger نشد یا رفتارش چیزی نبود که می‌خواستی، برگرد در Claude Project بگو تا
توضیح یا بدنه همان Skill را اصلاح کنم.
